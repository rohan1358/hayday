Dekorasi ini merupakan aset visual yang bisa dibeli, dipasang, dipindahkan lewat ATUR dan disimpan kembali. Belum ada sistem riset, pengolahan kompos atau simulasi ekosistem baru.

Stroberi biasa tetap Lv4 dengan lahan dan alur lama.
Bibit Stroberi Kristal adalah bibit tertinggi di Lv20:
- 160 koin per bibit.
- Ditanam pada petak yang sudah ada; jumlah lahan tidak berubah.
- Tumbuh 420 detik (7 menit), memakai sistem waktu dan perawatan lama.
- Empat tahap gambar: bibit, tanaman muda, bunga/buah muda, matang.
- Hasil 3 stroberi kristal, 80 XP per panen.
- Harga jual 225 koin per buah.
- Panen tetap ditolak jika gudang tidak cukup; tanaman tidak hilang.
- Mendukung simpan/muat dan pertumbuhan saat game ditutup.

Tidak menambahkan stroberi lava, bulan atau emas sebagai tanaman/dekorasi baru. Tidak mengganti gambar/alur stroberi biasa. Tidak membuat APK baru.

PNG dibuat dengan built-in image_gen; potongan aset dan anchor disiapkan lewat pipeline Godot. Prompt lengkap ada pada prompts-and-notes.json. Manifest berisi level, nama, file PNG dan titik pijak.

Pengujian: progres stroberi/kristal, batas level pembelian/pemasangan, save/load, gudang penuh, penjualan: lulus. Regresi dekorasi: 0 gagal. Smoke test: 0 gagal. Hybrid movement/interactions: 60 checks, 0 gagal.
