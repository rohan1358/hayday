# Aset karakter dan aksesori

Dibuat dengan built-in image_gen, memakai gambar referensi dari pengguna. Game tetap menggunakan kebun 2D.

Aset terpasang:
- hayday/assets/wardrobe/characters.png: 4 kolom musim Semi, Panas, Gugur, Dingin; baris laki-laki dan perempuan.
- hayday/assets/wardrobe/accessories.png: 4 kolom kepala, mata, leher, tas; 4 baris musim Semi, Panas, Gugur, Dingin.

Salinan deliverable:
- kostum-empat-musim.png
- aksesori-empat-musim.png

Prompt karakter:
Create ONE production game character sprite atlas on a genuinely transparent background, 4 columns x 2 rows, exactly eight evenly spaced equal cells, no text no outlines no panels. Reference image is the exact character identity and polished soft 3D-rendered illustration style to preserve: same happy oversized brown eyes freckles brown hair faces boots body proportions. Row 1 the boy from reference repeated in four seasonal full body outfits; row 2 the braided girl from reference repeated in same four seasons. Columns spring / summer / autumn / winter. Spring boy yellow shirt blue denim overalls, girl coral shirt sage green overall shorts exactly reference. Summer light linen short overalls and rolled sleeves aqua pastel accents. Autumn warm rust cardigan over overalls long trousers leather boots. Winter quilted teal coat warm long trousers fur lined boots. NO headgear NO glasses NO scarves: these are separate equip overlays. All eight stand facing camera slightly 3/4, same scale and aligned feet, arms relaxed, complete head and boots with generous empty 12% padding within EACH equal cell. Beautiful detailed fabric, silky hair, rounded childlike toy aesthetics as reference; no primitive low poly shapes. Entire sprite sheet transparent.

Prompt aksesori:
Create ONE game inventory sprite atlas: exactly 4 columns by 4 rows, sixteen equal cells on a genuinely TRANSPARENT background. No labels, no text, no grid lines, no bodies or mannequins. Match attached reference's high quality soft 3D illustration aesthetic, warm fabric/leather textures, rounded cute proportions. Each standalone accessory isolated, centered in its equal cell with 15% padding, facing forward, suitable for overlaying onto the reference child farmer. Columns always HEAD / FACE / NECK / BAG. Row1 SPRING: floral straw hat; delicate round gold glasses; small sage floral neckerchief; wicker flower satchel. Row2 SUMMER: cream sunhat with aqua ribbon; teal sunglasses; lemon bandana; straw shoulder bag with sunflower. Row3 AUTUMN: rust wool beret; tortoiseshell round glasses; orange knitted scarf; brown leather acorn satchel. Row4 WINTER: teal pompom beanie; white snow goggles; thick cream knitted scarf; burgundy mini winter backpack. All hats viewed slightly front threequarter, glasses perfectly front-facing lens pair without face. Scarves standalone wearable neck shape. Entire silhouettes complete, absolutely no overlaps between cells. Material polished like reference boots and clothes.

Validasi: pilihan gender, kostum dan aset aksesori terbaca, empat slot, pembelian dan pemakaian ulang tanpa biaya ganda, koin tidak cukup, lepas aksesori, save/load. Snapshot visual editor dan katalog diperiksa.
