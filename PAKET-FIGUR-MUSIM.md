# Paket figur musim lengkap

Sumber asli: codex-clipboard-6613fde8-596f-4248-9200-43e0e211c4bd.png. Disimpan di hayday/assets/wardrobe/seasonal_figures_source.png. Enam belas figur utuh dipisahkan dari kertas/label ke hayday/assets/wardrobe/seasonal_figures/. Tidak ada desain ulang atau gambar hasil generasi baru.

Paket: Semi, Panas, Gugur, Dingin; masing-masing laki-laki dan perempuan. Setiap paket berisi seluruh figur yang sudah berpakaian dan memakai aksesori seperti contoh, dengan pasangan depan dan belakang. Renderer mengganti figur secara utuh; lapisan aksesori terpisah tidak dipakai lagi. Pergerakan dan aktivitas tetap memakai animasi karakter game. Arah depan/serong depan memakai tampak depan, arah belakang/serong belakang memakai tampak belakang dari sumber.

Satu pembelian 115 koin mencakup dua tampak sekaligus. Tombol PASANG PAKET untuk paket milik pemain tidak menarik koin. Paket Semi kedua gender menjadi set awal. Pilihan paket disimpan terpisah per gender dan bertahan setelah muat ulang. LEPAS PAKET kembali ke karakter dasar. Koleksi kostum lama tetap tersimpan; pembelian aksesori lama versi 4–6 selain set Semi gratis direfund sekali per item ketika migrasi.

Tes lulus: seasonal_pack_test (pembelian sekali, pemasangan dua tampak, penolakan koin kurang, ganti gender, lepas/pasang kembali tanpa bayar, simpan/muat, migrasi/refund), cheerful_design_test (0 kegagalan), first_farm_test (0 kegagalan). Visual 16 figur lengkap dan editor toko diperiksa. Bonus persiapan musim membaca musim paket yang sedang dipakai.
